# Approved Reference Sheet Specification

A character version is not considered production-ready until it has an approved reference sheet.

## Required views

- face front
- face 3/4
- face side
- full-body front
- full-body 3/4
- neutral pose
- 3–6 representative expressions

## Reference-image policy

Prefer reference images over re-describing permanent visual traits in every scene.

When an image agent supports:
- character reference
- image reference
- identity reference
- image conditioning
- control image

use the approved sheet.

## Change control

If a permanent feature changes:
1. increment the character version
2. update the canonical character file
3. generate a new reference sheet
4. approve it
5. use only the new version in new scenes

Do not mix two character versions inside one continuity sequence.
