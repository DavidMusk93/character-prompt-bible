# Character Sheet Prompt

Use this once a canonical character definition is approved.

```text
Create a clean reference sheet for {{character_id}} using {{style_id}}.

Show the same exact character in:
1. front portrait
2. three-quarter portrait
3. side portrait
4. front full body
5. three-quarter full body
6. neutral standing pose
7. happy expression
8. focused expression
9. mildly frustrated expression

Maintain identical:
- facial geometry
- eye geometry
- hairstyle silhouette
- age appearance
- body proportions
- signature outfit
- footwear

Use a plain warm-neutral background.
Keep lighting flat and readable.
No dramatic perspective.
No scene props unless they are permanent identity anchors.
No text except a small character_id label if the model renders text reliably.
```

Approve one sheet per character version and store it as the primary image reference.
