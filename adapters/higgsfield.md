# Higgsfield Adapter

Use the approved character sheet or canonical reference image as the main-character reference when the selected workflow supports reference images or a main-character mode.

## Assembly order

1. select the approved reference image
2. bind it as the character / main-character reference
3. keep canonical identity text short and consistent
4. add the shared style specification
5. add scene-specific action, environment, framing, and lighting

## Rule

Model-specific presets may affect cinematography or rendering, but must not redefine character identity.

If a preset causes large identity drift, prefer a more neutral preset and preserve the approved reference image rather than rewriting the canonical character spec.
